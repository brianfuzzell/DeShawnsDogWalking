# 🐕‍🦺 🐩 DeShawn's Dog Walking
This [Nashville Software School](https://nashvillesoftwareschool.com/) project gave me an opportunity to build a full stack application with a React client and .NET API. 

The web application provides professional dog walker a solution to managing the dogs, walkers, and cities they work in. CRUD is supported in the application: Create data, Read data, Update data, Delete data.

## Instructions
Try to avoid completing the entire API, and only then starting on the React client. We recommend you build the API and the front end concurrently, _feature by feature_, rather than trying to anticipate all of the needs for the API in the beginning. For this reason, (and because it is the column furthest to the right), aside from the setup instructions and the starter code, the main features of the app will only be described in the user stories. Use the tools you have already learned (building an ERD, making wireframes, etc) to plan your work on this project.
